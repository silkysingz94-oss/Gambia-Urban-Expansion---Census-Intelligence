METHODOLOGY AND DATA NOTES
Administrative filtering: the selected region, district, ward or EA determines the features used for all calculations. A more specific selection takes precedence over its parent selection.

Aggregation: numeric values are summed from available EA records. Missing values are excluded rather than treated as measured zero values.

Data distinction: Census, mapped and LS fields are displayed separately. They are not assumed to be interchangeable.

Completeness fields: Comp_map_23 and Comp_ls_23 are summed only where numeric values are present. Their interpretation depends on the source dataset's definition.

Limitations: this application does not invent missing census values or derive building counts from map appearance.
